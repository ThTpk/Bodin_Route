แก้ไขข้อมูลแผนที่

โหนด เส้นเชื่อม และรายละเอียดสถานที่

มีการแก้ไขที่ยังไม่ได้ส่งออก กลับไปหน้าแผนที่
กำลังโหลดข้อมูลแผนที่…
ชั้น

แสดงเฉพาะ 300 รายการแรกที่ตรงกับคำค้น ระยะทางคำนวณจากพิกัดโหนดให้อัตโนมัติ แต่แก้เป็นค่าที่วัดจริงได้

ส่งออกไฟล์

ดาวน์โหลดแล้วนำไปวางทับไฟล์เดิมในโฟลเดอร์ data/ ของโปรเจกต์ จากนั้น commit ขึ้น GitHub ระบบจะใช้ข้อมูลใหม่ทันที

นำเข้าไฟล์

เลือกไฟล์ JSON ที่แก้ไว้เพื่อโหลดกลับมาแก้ต่อ ระบบจะตรวจชนิดไฟล์ให้อัตโนมัติ

ข้อมูลที่บันทึกไว้ในเบราว์เซอร์

การแก้ไขจะถูกเก็บไว้ในเครื่องโดยอัตโนมัติ (localStorage) เพื่อไม่ให้หายเวลาปิดหน้าเว็บ แต่ ไม่ได้แก้ไฟล์ในโปรเจกต์ให้ ต้องส่งออกแล้วนำไปวางทับเอง

ผลการตรวจสอบ

ยังไม่ได้ตรวจสอบ กด "ตรวจสอบข้อมูล" ที่แถบด้านบน
