# กราฟเส้นทางภายในอาคาร — มุมมอง 3 มิติ

เว็บแสดง **โหนด (node)** และ **เส้นเชื่อม (edge)** จากไฟล์ข้อมูลเป็นภาพ 3 มิติที่หมุนได้
พร้อมค้นหาเส้นทางที่สั้น/เร็วที่สุดด้วย Dijkstra และ A*

ไม่มีแผนที่ ไม่มีผังพื้น ไม่มีภาพพื้นหลัง — ทุกอย่างที่เห็นบนจอมาจาก
`data/nodes.json` และ `data/edges.json` เท่านั้น

เป็นเว็บ static ล้วน (HTML + CSS + JavaScript ไม่มี build step ไม่มี dependency ภายนอก)
การวาดภาพ 3 มิติเขียนเองบน `<canvas>` 2D ไม่ได้ใช้ WebGL หรือไลบรารีใด ๆ

## โครงสร้างข้อมูลที่จำลอง

| ส่วนประกอบ | จำนวน | รายละเอียด |
|---|---|---|
| อาคาร | 3 | อาคาร 1, 2, 3 |
| ชั้นต่ออาคาร | 3 | ชั้น 1–3 |
| ห้องต่อชั้น | 10 | ห้อง 01–10 |
| โหนดห้องเรียน | 90 | 3 อาคาร × 3 ชั้น × 10 ห้อง |
| โหนดบันได | 27 | 3 อาคาร × 3 ชั้น × บันได 3 ตำแหน่ง |
| โหนดทางเชื่อมระหว่างอาคาร | 2 | อาคาร 1–2 และ 2–3 ที่ชั้น 2 |
| **รวมโหนด** | **119** | |
| **รวมเส้นเชื่อม** | **148** | ทางเดิน 108 + บันได 36 + ทางเชื่อม 4 |

**บันได** มี 3 ตำแหน่งในทุกอาคารและทุกชั้น

| รหัส | ตำแหน่ง |
|---|---|
| ก | ก่อนห้อง 01 |
| ข | ระหว่างห้อง 05 กับห้อง 06 |
| ค | หลังห้อง 10 |

แต่ละชั้นมีโหนดบันไดของตัวเอง (เช่น `b1-f1-stA`, `b1-f2-stA`, `b1-f3-stA`)
แล้วเชื่อมชั้นต่อชั้นด้วยเส้นเชื่อมชนิดบันได จึงเป็นทางเดียวที่ข้ามชั้นภายในอาคารได้

**ทางเชื่อมระหว่างอาคาร** อยู่ที่ **ชั้น 2** เท่านั้น 2 จุด
เชื่อมบริเวณ **ห้อง 10** ของอาคารหนึ่งกับ **ห้อง 01** ของอีกอาคาร
แต่ละจุดเป็นโหนดของตัวเองชนิด `bridge` (`br-b1b2-f2`, `br-b2b3-f2`)

ทางเดินในแต่ละชั้นเรียงเป็นสายเดียวกัน

```
[บันได ก] 01 02 03 04 05 [บันได ข] 06 07 08 09 10 [บันได ค]
```

**รหัสห้อง** ใช้รูปแบบ `[อาคาร][ชั้น][เลขห้อง]` เช่น `2305` คือ อาคาร 2 ชั้น 3 ห้อง 05

## ความสามารถ

- **ภาพกราฟ 3 มิติที่หมุนได้** — ลากเพื่อหมุน (yaw/pitch), Shift+ลาก หรือคลิกขวาลาก เพื่อเลื่อน,
  สกรอลล์เพื่อซูม, บนมือถือใช้นิ้วเดียวหมุนและสองนิ้วซูม, ปุ่มลูกศรบนคีย์บอร์ดก็หมุนได้
- **ปรับระยะห่างระหว่างชั้น** ด้วยแถบเลื่อน เพื่อให้แยกชั้นด้วยตาได้ง่ายขึ้น
- **เน้นทีละชั้น** — เลือกชั้นแล้วชั้นอื่นจะจางลง (ไม่ได้ซ่อน) จึงยังเห็นบริบททั้งกราฟ
- **หมุนอัตโนมัติ**, เปิด/ปิดระนาบอ้างอิงของชั้น, เปิด/ปิดป้ายชื่อ
- **ค้นหาเส้นทาง** ด้วย Dijkstra หรือ A* เลือกเกณฑ์ระยะทางหรือเวลา และเลี่ยงบันไดได้
- **คำแนะนำการเดินทีละขั้น** พร้อมบอกจุดขึ้น-ลงบันไดและจุดข้ามทางเชื่อมระหว่างอาคาร
- **หาโหนดที่ใกล้ที่สุด** (บันได / ทางเชื่อม / ห้องเรียน) ด้วย multi-target Dijkstra
- **กรองตามประเภทโหนด** จากแถบสัญลักษณ์
- **แชร์เส้นทางผ่าน URL** เช่น `#from=b1-f1-r01&to=b3-f3-r10&by=time`

## เริ่มใช้งาน

**ต้องเปิดผ่านเว็บเซิร์ฟเวอร์** เพราะหน้าเว็บโหลดข้อมูลจากไฟล์ JSON ด้วย `fetch()`
ซึ่งเบราว์เซอร์จะบล็อกถ้าเปิดไฟล์ด้วย `file://` ตรง ๆ

```bash
python -m http.server 8000
```

แล้วเปิด <http://localhost:8000>

ถ้าใช้ Node.js:

```bash
npx serve .
```

## รูปแบบไฟล์ข้อมูล

### `data/nodes.json`

```json
{
  "id": "b1-f2-r10",
  "name": "ห้อง 1210",
  "type": "classroom",
  "building": "b1",
  "floor": 2,
  "x": 44.0,
  "y": 0.0,
  "description": "อาคาร 1 ชั้น 2 ห้องที่ 10 จาก 10",
  "photo": "",
  "aliases": ["1210", "1/2/10"],
  "source": "สร้างจาก tools/generate_data.py ตามโครงสร้างอาคารที่กำหนด"
}
```

| ฟิลด์ | ความหมาย |
|---|---|
| `id` | รหัสโหนด ต้องไม่ซ้ำ ใช้อ้างอิงใน `edges.json` |
| `type` | `classroom` / `stairs` / `bridge` (กำหนดสีและสัญลักษณ์ใน `js/view3d.js`) |
| `building` | รหัสอาคารใน `buildings.json` — เป็น `null` ได้ เช่น โหนดทางเชื่อม |
| `floor` | ชั้น ใช้คำนวณความสูงบนแกนตั้งของภาพ 3 มิติ |
| `x`, `y` | พิกัดบนผัง หน่วยเมตร |
| `aliases` | คำค้นเพิ่มเติม เช่น รหัสห้อง |

### `data/edges.json`

```json
{ "from": "b1-f1-stA", "to": "b1-f2-stA", "distance": 7.5,
  "time": 20, "type": "stairs_up", "bidirectional": false }
```

| ชนิด | ความหมาย | น้ำหนักในชุดข้อมูลนี้ |
|---|---|---|
| `corridor` | ทางเดินในชั้นเดียวกัน | 4 เมตร / 3 วินาที |
| `bridge` | ทางเชื่อมระหว่างอาคาร (ชั้น 2) | 13 เมตรต่อข้าง / 10 วินาที |
| `stairs_up` | บันไดขึ้นหนึ่งช่วงชั้น | 7.5 เมตร / 20 วินาที |
| `stairs_down` | บันไดลงหนึ่งช่วงชั้น | 7.5 เมตร / 15 วินาที |

บันไดขึ้นกับลงใช้เวลาไม่เท่ากัน จึงเก็บเป็นเส้นเชื่อม **มีทิศทาง** แยกกันสองเส้น
(`bidirectional: false`) ส่วนทางเดินและทางเชื่อมเป็นสองทาง

## วิธีแก้ไขข้อมูล

### ทางที่ 1 — แก้ที่ตัวสร้างข้อมูล (แนะนำ)

แก้ค่าคงที่ด้านบนของ [`tools/generate_data.py`](tools/generate_data.py)
เช่น จำนวนอาคาร จำนวนชั้น จำนวนห้อง ตำแหน่งบันได ชั้นที่มีทางเชื่อม ระยะทาง หรือเวลาเดิน
แล้วรัน

```bash
python tools/generate_data.py
```

ไฟล์ทั้งสามใน `data/` จะถูกเขียนทับใหม่ทั้งหมด

### ทางที่ 2 — แก้ไฟล์ JSON ตรง ๆ

แก้แล้วตรวจด้วย

```bash
python tools/validate_data.py
```

สคริปต์จะตรวจ id ซ้ำ, edge ที่อ้างถึงโหนดที่ไม่มีอยู่, ค่า `distance`/`time` ที่ไม่ถูกต้อง,
โหนดที่ไม่มีเส้นเชื่อม และตรวจด้วย BFS ว่ากราฟยังเชื่อมต่อกันครบทุกโหนด

## การฉายภาพ 3 มิติ

`js/view3d.js` ทำงานสี่ขั้นตอนต่อหนึ่งเฟรม

1. **แกนตั้ง** — `z = (floor - ชั้นต่ำสุด) × ระยะห่างระหว่างชั้น`
   ค่าระยะห่างนี้ปรับได้จากแถบเลื่อนเพื่อให้เห็นชั้นชัดขึ้น และ**ไม่มีผลต่อการคำนวณเส้นทาง**
2. **หมุน** รอบแกนตั้งด้วยมุม `yaw` แล้ว**เอียง**ด้วยมุม `pitch`
3. **ฉายแบบเปอร์สเปกทีฟ** — `scale = focal / (dist + depth)`
   จุดที่ไกลกว่าจึงเล็กลงและโหนดที่อยู่ใกล้กล้องจะวาดใหญ่ขึ้น
4. **เรียงลำดับวาดจากไกลไปใกล้** (painter's algorithm) เพื่อให้การบังกันถูกต้อง
   ส่วนเส้นทางที่ค้นหาจะถูกวาดไว้บนสุดเสมอ

ปุ่ม "พอดีหน้าจอ" คำนวณระยะกล้องแบบปิด (closed form) จากโหนดทุกตัว
โดยแก้สมการ `|x| × focal / (dist + depth) = ครึ่งความกว้างจอ` แล้วเลือกค่าที่มากที่สุด

## ทฤษฎีกราฟที่ใช้

| อัลกอริทึม | ใช้ทำอะไร | ความซับซ้อน |
|---|---|---|
| **Dijkstra** | เส้นทางน้ำหนักรวมต่ำสุด ใช้ binary min-heap | O((V + E) log V) |
| **A\*** | Dijkstra + heuristic ระยะยุคลิด 3 มิติ (admissible) | เท่ากันแต่สำรวจน้อยกว่า |
| **Multi-target Dijkstra** | หาโหนดประเภทที่ต้องการที่ใกล้ที่สุด เดินกราฟรอบเดียว | O((V + E) log V) |
| **BFS** | ตรวจความเชื่อมต่อของกราฟ (`tools/validate_data.py`) | O(V + E) |

heuristic ของ A* ใช้ระยะเส้นตรง 3 มิติซึ่งไม่มีทางเกินระยะจริง จึงยังได้เส้นทางสั้นที่สุด
เหมือน Dijkstra ทุกประการ

## ข้อจำกัด

- ผังนี้เป็น **ผังจำลองตามโครงสร้างที่กำหนด** ไม่ใช่แบบแปลนของอาคารจริง
  ระยะทางและเวลาที่แสดงจึงเป็นค่าประมาณ
- ห้องแต่ละห้องแทนด้วยโหนดเดียวที่อยู่บนแนวทางเดิน (คิดเสมือนตำแหน่งประตูห้อง)
- ในชุดข้อมูลนี้ **บันไดเป็นทางเดียวที่ข้ามชั้นได้** ยังไม่มีลิฟต์หรือทางลาด
  ถ้าเปิดตัวเลือก "เลี่ยงบันได" แล้วปลายทางอยู่คนละชั้น จะหาเส้นทางไม่พบ
- ทางเชื่อมระหว่างอาคารมีเฉพาะที่ชั้น 2 การเดินข้ามอาคารจึงต้องขึ้น-ลงมาที่ชั้น 2 เสมอ
